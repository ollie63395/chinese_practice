# Cíhuì 词汇

Kho từ vựng tiếng Trung (tiếng Phổ thông) dành cho người Việt. Thêm những từ bạn học được, ôn lại bằng thẻ ghi nhớ, rồi vận dụng chúng trong bài luyện nói có bấm giờ. Mỗi người có tài khoản riêng; giáo viên theo dõi được việc học của mọi học viên.

## Tính năng

- **Tài khoản.** Đăng nhập bằng email hoặc tên đăng nhập. Từ vựng, hình ảnh và lịch sử luyện tập được lưu trên máy chủ, nên bạn tắt máy, tải lại trang hay đổi sang thiết bị khác đều không mất gì.
- **Học viên và giáo viên.** Tài khoản mới là tài khoản học viên: học viên chỉ thấy dữ liệu của chính mình. Giáo viên xem được (nhưng không sửa) từ vựng, lịch sử luyện tập và chi tiết từng buổi luyện nói của mọi học viên, đặt lại mật khẩu cho học viên, và đặt một tài khoản làm giáo viên.
- **Kho từ vựng.** Mỗi từ gồm chữ Hán, pinyin có dấu thanh, nghĩa tiếng Việt, một hình ảnh (không bắt buộc) và bao nhiêu nhãn tùy thích. Tìm theo chữ Hán, pinyin (có hay không có dấu thanh đều được), nghĩa hoặc nhãn, và gõ tiếng Việt không dấu cũng tìm được; lọc theo nhãn; sắp xếp theo ngày thêm hoặc theo pinyin A–Z.
- **Thẻ ghi nhớ.** Ôn mọi từ, hoặc chỉ những nhãn bạn chọn. Cho mặt trước hiện tiếng Trung hoặc nghĩa, đánh dấu từng thẻ *Đã thuộc* hay *Chưa thuộc*, rồi ôn lại những thẻ chưa thuộc.
- **Luyện nói.** Chọn số từ và thời gian nói. Các từ được bốc ngẫu nhiên (từ cả kho hoặc theo nhãn); bạn có thể bỏ, đổi hoặc thêm từ, rồi chuẩn bị bao lâu tùy thích, kèm ghi chú. Đồng hồ chỉ chạy khi bạn bắt đầu nói. Trong lúc nói, nhấn vào từng từ sau khi đã dùng. Hết giờ sẽ có tiếng chuông.
- **Lịch sử luyện tập.** Mỗi buổi luyện nói được ghi lại cùng các từ, thời gian và ghi chú. Mở một buổi để xem lại, luyện lại các từ đó, hoặc xóa đi.
- **Sao lưu & khôi phục.** Tải mọi thứ (kể cả hình ảnh) về thành một tệp, hoặc đưa một tệp sao lưu vào tài khoản: dữ liệu từ phiên bản cũ chỉ lưu trong trình duyệt, hay một danh sách từ giáo viên gửi cho cả lớp.
- Dùng được trên điện thoại và máy tính, ở chế độ sáng và tối. Từ vựng được đọc to bằng giọng tiếng Phổ thông nếu trình duyệt có sẵn.

## Dữ liệu của bạn

Mọi thứ được lưu trong tài khoản của bạn trên máy chủ (Supabase), và cần có mạng để dùng. Bạn vẫn đăng nhập sau khi tải lại trang hoặc khởi động lại máy; trên thiết bị khác, chỉ cần đăng nhập lại.

Học viên chỉ thấy dữ liệu của chính mình. Giáo viên xem được dữ liệu của mọi học viên nhưng không sửa hay xóa được. Quy tắc này do chính cơ sở dữ liệu áp dụng, không chỉ do giao diện.

Quên mật khẩu: tài khoản dùng email có thể tự nhận liên kết đặt lại mật khẩu. Tài khoản dùng tên đăng nhập thì nhờ giáo viên đặt lại.

## Gõ pinyin

Trang web không thể tự chuyển bàn phím của bạn sang tiếng Trung, nên ô **Pinyin** tự đổi số thanh điệu thành dấu ngay khi bạn gõ: `ni3 hao3` → nǐ hǎo.

- Gõ số thanh điệu (1–4) ngay sau mỗi âm tiết. Có thể viết liền (`ni3hao3` → nǐhǎo) hoặc cách nhau.
- `5` (hoặc `0`) là thanh nhẹ: `xie4xie5` → xièxie.
- `v` hoặc `u:` cho ra ü: `lv4` → lǜ, `nv3` → nǚ.
- Dấu nháy để tách âm tiết: `xi1'an1` → Xī'ān. Chữ hoa được giữ nguyên: `Bei3jing1` → Běijīng.
- Gõ thêm một số sau âm tiết đã có dấu sẽ đổi dấu đó: `hǎo` + `4` → hào.
- Pinyin đã có dấu dán từ nơi khác được giữ nguyên.
- **Hãy tắt bộ gõ tiếng Việt (Telex/VNI) khi gõ pinyin.** Nếu không, bộ gõ sẽ đổi chữ của bạn (`er` → ẻ, `dd` → đ, và với VNI thì `ni3` → nỉ). Cíhuì sẽ báo lỗi nếu thấy chữ tiếng Việt lẫn vào pinyin.

## Getting started

Requires Node.js 22.22 or newer, and Docker Desktop (running) for the local Supabase.

```bash
npm install
npm run db:start              # local Supabase in Docker; the first run downloads a few GB
cp .env.example .env.local    # then fill in the values db:start prints (see below)
npm run dev
```

Then open http://localhost:5173 and create an account. For local development, `.env.local` takes the URL, publishable key and secret key that `npm run db:start` prints (also shown by `npx supabase status`). Password-reset emails don't leave your machine: read them at http://127.0.0.1:54324.

To make an account a teacher locally, run this in `psql postgresql://postgres:postgres@127.0.0.1:54322/postgres`:

```sql
update public.profiles set role = 'teacher' where email = 'you@example.com';  -- or: where username = 'yourname'
```

To try it on a phone, it's simplest to point `.env.local` at a hosted Supabase project (see Deploying), run `npm run dev -- --host` and open the "Network" address it prints. Keeping the screen awake during a speech needs HTTPS, so that one feature won't work over a plain LAN address.

## Scripts

| Command            | What it does                                                                   |
| ------------------ | ------------------------------------------------------------------------------ |
| `npm run dev`      | Start the development server                                                   |
| `npm run build`    | Type-check and build the site into `dist/`                                     |
| `npm run preview`  | Serve the built site locally                                                   |
| `npm test`         | Run the unit tests (Vitest)                                                    |
| `npm run test:db`  | Test the database's access rules and the app's data functions (local Supabase) |
| `npm run test:e2e` | Run the browser tests (Playwright) on desktop and phone-sized screens (local Supabase) |
| `npm run db:start` | Start local Supabase and apply the migrations in `supabase/migrations/`        |
| `npm run db:stop`  | Stop local Supabase                                                            |
| `npm run db:types` | Regenerate `src/db/database.types.ts` after changing the schema                |

On Windows the browser tests use the installed Microsoft Edge. Elsewhere, run `npx playwright install chromium` once first. `test:db` and `test:e2e` sign up many throwaway accounts; `npx supabase db reset` wipes the local database clean.

## Deploying

The site is static (Vercel, Netlify, GitHub Pages…); the accounts and data live in a Supabase project.

1. **Before switching over**, if anyone used the earlier, browser-only version: open it and download a backup from **Sao lưu & khôi phục**. After signing in to the new version, restore that file into the account.
2. **Create a Supabase project** at supabase.com (Singapore is the closest region to Vietnam).
3. **Create the tables and access rules**: either run `npx supabase login`, `npx supabase link --project-ref <your project ref>` and `npx supabase db push`, or paste each file in `supabase/migrations/` into the dashboard's SQL Editor and run them in order (oldest first).
4. **Authentication settings** in the dashboard:
   - *Sign In / Providers → Email*: turn **Confirm email off**. Username accounts have no real address to confirm (they're stored as `<username>@users.cihui.invalid`).
   - *URL Configuration*: set the Site URL to your site's address, and add `https://<your site>/**` to the Redirect URLs, so password-reset links can come back to the app.
   - *Emails → SMTP Settings*: Supabase's built-in email only reaches your own team's addresses, a few times an hour. For students to receive password-reset emails, connect an email provider (Resend, Brevo, Postmark…). Until then, teachers can reset students' passwords.
5. **On Vercel** (or any host), set two environment variables from the Supabase dashboard, then redeploy:
   - `VITE_SUPABASE_URL`: *Project Settings → Data API*, e.g. `https://abcd.supabase.co`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`: *Project Settings → API Keys*, the publishable key (`sb_publishable_…`; the legacy `anon` key also works)

   Both are safe to ship in a website: the database's access rules do the guarding. Never put the secret (`service_role`) key in a `VITE_` variable.
6. **Make the first teacher**: sign up in the app, then in the SQL Editor run `update public.profiles set role = 'teacher' where email = 'you@example.com';`. From then on, teachers can make other accounts teachers from the **Học viên** page.

Vercel's settings: framework preset **Vite**, build command `npm run build`, output directory `dist`. The app uses `#/` URLs and relative asset paths, so it needs no rewrites and works from any sub-path.

Fonts load from Google Fonts (Be Vietnam Pro, Noto Sans SC) and jsDelivr (LXGW WenKai, from the `lxgw-wenkai-webfont` package). If they can't be reached, system fonts are used instead.

## Project layout

```
src/
  db/           Supabase data access (words, practice logs, pictures, profiles), the session and a small query cache
  lib/          Pinyin conversion, search, tags, backups, images, sound, speech and other helpers
  components/   Shared UI: layout, form fields, dialogs, the image and tag pickers, word and history lists
  pages/        One file per screen; pages/speaking/ holds the steps of a speaking practice
supabase/
  migrations/   The database schema and its access rules
  tests/        Tests of those access rules
e2e/            Playwright browser tests
```

Built with React 19, TypeScript, Vite, Tailwind CSS 4, React Router and Supabase.
